## 可复验命令

```sh
npm run build:client
npm test
npm run check
```

Windows 如 `python` 未在 PATH，用 `DSH_CHECK_PYTHON` 指定已有解释器。工作台 Host 固定回环；在经用户同意的独立安装窗口验证 Electron 和同机 Web，分别检查实际 `/health` 版本和会话草稿，不用旧服务输出作为证据。

## 发布前剩余的验收

1. 在真实 Web 和 Electron 分别安装、打开、手工发一条已填的 DSH 草稿、核对工具回执与回退。
2. 用合法非私密参考先验证本机单槽 Qwen 编辑、Anima 文生图；之后在私有工程补齐并批准 11 张 OC 图。实际耗时、显存和 PNG 一致性需记录。
3. 取得真实头与体 GLB 或已有 Blend；如需 Tripo，再确认账户可用额度、是否公开以及上传授权。
4. 语义分件、UV/贴图、比例对齐、转权和弹簧用真实角色验收；最后检查 VRM 1.0、元数据、Blend、真实动作与外部查看器。
