# 0.5.0 · 桌面与外部素材验证

验证范围：Windows 官方 `@deepseek-ai/dsh-desktop` 0.2.2-rc.3，实际应用进程、安装器与 `dsh-app://app` 渲染器。另设临时 Electron `userData`、`DSH_HOME`、工作台端口和工程，只使用程序生成的立方体、三角网格、PNG 和 VRM/VRMA 夹具。不修改用户常驻插件或角色工程。

| 检查 | 证据与边界 |
| --- | --- |
| 插件安装及导航 | 从桌面「添加插件」安装本地 0.5.0 tgz、启用、打开左侧 Avatar Studio。实际 renderer 显示八标签，项目页六关都有「导入本步素材」。不是单独页面或嵌入原版。 |
| 文件入口 | 通过官方渲染器真实 `input[type=file]` 填入本机文件；Host 收到路径导入。输入绝对路径登记 Blend。以 DOM 拖放事件测试没有本机路径时的 `application/octet-stream` 回退。未模拟系统鼠标从 Explorer 物理拖拽；目录选择器在真实桌面可见，未自动操控 OS 目录弹窗。 |
| 导入与采用隔离 | 六关共登记十条。PNG 原画、右视图和头部 GLB 各由独立操作采用。没有自动批准或 Tripo 扣分。 |
| 实际编辑 | Blender 5.3.0 + legacy companion：打开场景、追加 GLB、指定网格基色贴图、追加权重参考四次，各生成有父版本和输入指纹的 `.blend` 修订。基色 PNG 在 GLB 预览中自包含；权重参考不导出，无自动转权。源 Blend SHA-256 不变。 |
| VRM 动作预览 | 外部程序化 VRM + 1.20 秒 VRMA 在 Electron 的真实 WebGL 视口解析。连续帧像素指纹变化，暂停后稳定，复位后再次变化。未将外部 VRM 记作工程导出，不代表实角动作通过。 |
| 自动化保护 | 覆盖角色映射、类型与指纹、工程隔离、Host 版本、明确采用、老版状态读取、素材副本不覆盖、Blender 失败不取代基线、CORS 与 Session。Windows 在无创建符号链接权限时跳过对应旧用例。 |

未覆盖：真实角色生产验收、付费/本地生图运行、Tripo 出模、3.1 Gateway 的真实会话执行、同机正式 DSH Web profile 的端到端安装。外部素材许可赋权、体型/权重/物理表现、VRM 导出质量仍须用实际角色单独复核。`0.4.0` 的 [历史验证记录](VERIFICATION-0.4.0.md) 不替代本轮证据。
