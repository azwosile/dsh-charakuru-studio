# Avatar Studio 0.7.0

支持「原画重建」与「素体改型」双建模路线，采用「3 主工作区（主工作台 / 独立渲染台 / 资产库）+ 1 全局设置抽屉」架构，自适应 DSH 浅色与深色主题及中英双语。内置 Tripo 双通道（OpenAPI v3 实时余额与生成 + 1–4 视角浏览器工单）与 Blender 双通道（`dsh-blender-plugin` 228-op 契约层 + Agent Computer-Use GUI `checkout_gui`/`checkin_gui` 隔离工作副本），打通全 6 关证据审阅、同机 Web 二进制上传与目录浏览。

**实验版。** 结构校验、独立渲染与人工视觉审阅相互独立；工作台默认关闭云端扣费，不随包分发第三方专有模型，也不代用户花费积分或批准交付。
