# Avatar Studio 0.3.1

独立、本地优先的 DSH 角色工作台。显示品牌已独立，保留原包名与工具 ID 兼容现有项目。七标签包含资产、三维编辑、版本回滚及手工账户账本。

**实验版，不是全 P 验收完成版。** 实机确认 Blender 5.3/companion 3.0.6 的另存、缩放回滚、显式权重及 VRM 结构导出；服装动作质量和跨服装角色仍待人工验收。云端默认禁用，生产接口未实测，账本不自动查询供应商余额。
