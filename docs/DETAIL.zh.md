# Avatar Studio 0.10.0

支持「原画重建」与「素体改型（Route 2）」双建模路线，采用「3 主工作区（主工作台 / 独立渲染台 / 资产库）+ 1 全局设置抽屉」架构，自适应 DSH 浅色与深色主题及中英双语。`0.10.0` 在 `0.9.0` 的 25 项结构化建模工序、3D 世界空间三视图、`Y=0` 身高标尺、内置 MIT/CC0 循环漫步 VRMA 与无 Agent VRM 1.0 元数据导出基础上，进一步加固 Blender 4.2 LTS / 5.x 与 Cycles 描边/形态键/VRM 插件枚举兼容、Cordis 4 服务访问与回环安全（`Host` 校验、`Referrer-Policy`、413 超限、Windows 保留目录拦截）、3D 视口异步加载竞态及 Tripo 幂等与 Qwen 采样器参数隔离。

**实验版（内部验证阶段）。** 结构校验、独立渲染与人工视觉审阅相互独立；工作台默认关闭云端扣费，不随包分发第三方专有模型，也不代用户花费积分或批准交付。
