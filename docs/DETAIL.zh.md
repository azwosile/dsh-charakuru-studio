# Avatar Studio 0.4.0

独立的 DSH 角色工作台。六工序、带同朝向对照的头体图库、11 槽预案和单槽补做、DSH 会话草稿、Blender 不可变修订与人工账本。保留包名和工具 ID；无需原版 Charakuru。付费路径默认关闭。

**实验版。** 支持前三关资产证据审批；后三关有实验工序，仍需真实角色、动作及外部查看器验收。模型协议适配不等于已经运行供应商服务。
