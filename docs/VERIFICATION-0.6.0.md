# Avatar Studio 0.6.0 · 验证与边界

## 可重复检查

- `npm ci && npm run build:client && npm run check && npm test`（本轮 Node 24）。校验 DSH 入口、资源、JS 和 Python AST、两路线状态分离、六关素材、外部 Blend/GLB/PNG/VRM/VRMA、渲染请求/产物指纹、当前修订变化、旧图只读、超时不重发、仅人可审阅、精确 loopback CORS 和 Gateway 调用者绑定。
- `npm pack --ignore-scripts --json`；在单独目录解包跑测试，不从源目录引用内容。Windows `DSH_CHECK_PYTHON` 可指定本机 Python。Windows 无 symlink 权限时，仅跳过对应路径逃逸夹具，不放松实现。
- 软件包包括代码、技能、文档、检查脚本与程序化测试夹具定义，不含研究档案、模型、渲染图、账号、外部贴图或用户工程。
